# Jeu de photos privé (usage personnel)

Ce dossier reçoit les photos de référence personnelles et leurs masques générés par
`tools/photoseg/build_private_set.py`. Son contenu (hors ce fichier) n'est **jamais** versionné :
le dépôt est public et ces photos ne doivent pas être redistribuées.

Quand `photo_views.json` est présent, l'app propose le choix **Photo / 3D** dans l'atelier et le menu.
Sans lui, l'app utilise les visuels 3D du projet.
